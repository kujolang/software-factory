# Local context pipeline

The optional context adapter runs the pinned upstream Scout 1.1.0, Scent 1.1.0, and Redact 1.1.0 through Kujo 1.9.0. `config/context.lock.json` records exact commits and SHA-256/size identities for the complete executable modules, upstream configuration, version files and licenses. `node scripts/setup-context.mjs` installs only those files through pinned Git object reads, verifies every byte and never runs an upstream installer or repository script. No sibling checkout or global tool installation is required. Setup needs network access; already installed dependencies verify offline.

`factory context verify` verifies those runtime files. `factory context build SOURCE OPTIONS.json` builds a private local pack. Options are an explicit `files` array, a task string, an optional `budget` (256–32,000 estimated tokens, default 4,000), and an optional receipt `parent` directory. Source paths must be plain files under SOURCE. The adapter accepts at most 100 unique files, 100 KB per file and 1 MB in total. It rejects traversal, symlink ancestors, invalid UTF-8 and common credential/metadata directories or filenames. These exclusions are not a complete secret detector.

The controller copies selected bytes into a private snapshot and records original file paths and hashes. Fresh empty Git metadata prevents Scent from discovering a parent repository; source Git configuration, credentials, filters and hooks are never copied. Scout runs from a separate trusted working directory so an input `config.json` cannot control Scout configuration. All tools receive minimal environments and bounded execution/output limits. Repository code, package scripts and commands found in documentation are never executed.

Scout produces deterministic structural discovery and dependency/security observations. Scent selects task-relevant context within the supplied source set and retains selection/truncation/exclusion manifests. Redact sanitizes the Markdown using a controller-owned deterministic policy and independently runs its leakage verifier. Medium/high residual risk blocks the pack. A successful deterministic check is not a guarantee that every secret has been found. The final Markdown is also constrained by an explicitly estimated character/4 token budget; this is not provider tokenizer accounting.

The binding identifies every supplied source file, source aggregate identity, exact tool commits, Scout and Scent manifest hashes, sanitized Markdown hash and Redact verification output. Source hashes retain provenance without treating generated summaries as replacements for source. Scout observations and canonical Scent manifests remain separate inspectable evidence. No tool output is granted execution, acceptance, review or deployment authority.

Only `context.md` is the candidate handoff artifact; it still requires human privacy review. The workspace contains original source snapshots, Scout output, unsanitized intermediate context and private audit data. Treat the entire workspace as sensitive: do not export it automatically, send it to external telemetry or commit it. Failed attempts retain their receipts and failure record. The adapter does not yet automatically feed packs to mission agents, perform durable retrieval, reuse verified findings, enforce a semantic privacy policy, or provide an authenticated context signature.

Qualification: `node --test tests/context.test.mjs` runs the real pinned tools over synthetic fixtures, confirming bounded source selection, native output contracts, known-pattern redaction and no candidate execution. This qualifies the narrow local data path on the tested host/runtime, not arbitrary language analysis or comprehensive privacy removal. Redact documents Kujo 1.5.0 upstream; this adapter's tested Kujo 1.9.0 compatibility is scoped to these contracts.

PackWrite, Muzzle, RAG, Concord, Fence, ChangeBucket and PatchBrief retain their audit decisions in the capability matrix; this module does not silently substitute for their engines or claim they are integrated. Scout findings are advisory, not security release gates. Further adapters require their own source review and qualification.
