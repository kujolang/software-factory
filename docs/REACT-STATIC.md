# Optional React static runtime

The qualified profile is React18.3.1 with react-dom18.3.1, using React.createElement in one ESM component. JSX, SSR, arbitrary package graphs, npm scripts, framework servers and plugins are unsupported. This runtime verifies a supplied component; model-backed construction is a separate workflow and is not yet qualified.

Use `node scripts/react-static.mjs prefetch OPTIONS.json` with exactly `destination` for a new local cache. This explicitly fetches five SRI-pinned public packages and runs the qualified npm11.20.0 advisory query in a clean environment. No package is installed or executed on the host. Cache integrity, the exact lock, zero known audit findings and a seven-day observation-age bound are checked on admission. Advisory responses are time-specific and unsigned.

Use `verify OPTIONS.json` with exactly `sourceFile`, `packFile`, `cacheDirectory`, and a fresh `evidenceDir`. The source is JSON with exactly `app` and `style` strings. `app` must default-export a React component and may use the already installed global React API. The controller owns the HTML, bootstrap, ReactDOM.createRoot call, dependency lock, static server and independently reviewed sealed acceptance pack. Source cannot replace any of them.

The trusted build runs npm ci offline with ignore-scripts/no-bin-links inside the existing qualified Workcell image. Fixed production assets, source and MIT license notices become root-owned read-only output. The trusted server serves only those known names; candidate code executes in the isolated browser. The build, served artifacts, exact pack/browser observations, native Lens desktop/mobile/console/network/accessibility evidence and cleanup records are retained. The returned result grants no release or deployment approval. Exported public assets retain both upstream MIT licenses.

Actual qualification passed an interactive counter/form, wrong-counter rejection, hostile markup rejection and external-fetch rejection. A final positive run additionally verified the license-bearing artifact and frozen cache snapshots. Evidence: `.runtime/react-static-qualification/qualification.json`. The initial failed bootstrap expectation remains retained: react-dom package18.3.1 reports runtime version18.3.1-next-f1338f8080-20240426; the exact expectation now matches its pinned source. These are same-host Workcell/browser observations, not clean-machine or broad React compatibility claims.

Tests: `node --test tests/react-static.test.mjs`. Coordinated actual engine qualification: `node scripts/qualify-react-static.mjs`, after explicit prefetch. No engine image is pulled or built by this profile. Automatic accessibility checks are not WCAG certification, and screenshots alone are not visual-baseline approval.
