# Known limitations

Final release acceptance is pending the current-source qualification matrix. The inventory distinguishes installed contracts, qualified execution paths, optional capabilities and unavailable upstream interfaces.

- The installed catalogs contain85roles,136complete skill packages and45upstream workflow kits. All28Chain roles have passing independent semantic judgments for one role-specific scenario and deterministic contract/effect/handoff checks. This is not universal role competence. Upstream skill packages lack a uniform dependency schema; the factory does not invent dependencies or permissions.
- All20software lifecycle types have bounded executable routes. They are not universal repository/framework workflows. Standard application/repository construction accepts the documented dependency-free Node shape. Python, TypeScript, Go, Rust and Kujo construction accepts the reviewed single-file CLI profiles. React support is a separately locked static profile; JSX, arbitrary bundlers, server rendering and lifecycle scripts are outside it.
- Dependency upgrades currently qualify the explicit semver7.7.2→7.7.3CLI path. React has its own five-package closure. Native npm audit records are time-specific, hash-bound observations with freshness checks, not proof that all dependencies or operating-system images are vulnerability-free. Kennel remains a declaration validator; Fence remains architecture analysis.
- SQLite migrations run only against disposable controller-owned seed databases. Candidate-specific forced rollback, forward migration, schema/data checks and restart are verified. The result does not authorize a production migration. PostgreSQL and arbitrary migration tools are not qualified.
- Performance qualification covers one frozen stateless GET request, bounded warmups/samples, correctness checks and observed median thresholds under the recorded image. It provides no statistical confidence or universal speedup claim. Generic retry/recheck rejects performance missions to avoid dropping the original baseline/policy.
- Native Spec validates frozen projections and exports. Change-impact reporting traces structural requirement/test changes and potential contradictory observations; neither it nor model review proves semantic completeness. Fixed defect-seeding tests establish detection of two converter defects, not a general mutation score. A seal establishes identity, not reviewer authentication or correctness.
- Codex has actual construction and release evidence; local Ollama has actual structured-output and independently verified revalidation evidence. This does not qualify every model for every role. OpenAI/Anthropic/Gemini SDK adapters have protocol fixtures but no live credential qualification here. Missing usage and cost remain unknown; unsupported monetary ceilings fail closed.
- Native Redact plus selected supplementary credential patterns guard real provider inputs and new candidate-source gates. No matched secret values are retained in scan receipts. Detection is deliberately bounded and cannot prove absence of every secret or encoded exfiltration payload. Context snapshots and original evidence can contain private source and require operator handling.
- Lens browser evidence is independently executed in Workcell. Optional visual comparisons require the separately qualified image and exact retained baseline origin, viewport, image and explicit local approval. Pixel thresholds are empirical, not comprehensive visual correctness or accessibility certification. A caller-supplied approval identity is an attributed local assertion, not cryptographic authentication.
- Documentation activates Publishing House editorial review and a separate final reviewer. WebOps reviews retained local Lens evidence as an advisory report; it does not claim a current external-site crawl or visual inspection by a text-only model. VideoOps is discoverable and only routed for an explicit media request; production media execution is not a software-factory release capability.
- Native Ability, Relay, Tribunal, RAG, PackWrite, Muzzle and change/context adapters use their inspected contracts. Definition validation, receipt validation and retrieval do not imply Ability Gateway hosting, external Relay delivery, model tribunal authority or enterprise knowledge governance. Missing/private Ward/Capsule and other unavailable interfaces remain explicitly disabled. Foreman remains excluded.
- Recovery admits only unchanged, quiescent completed/pending native checkpoints under the original deadline and new explicit authorization. Started uncertain effects, protected approvals and copied archival state are not automatically replayed. Retention preserves failed/active evidence and archives before removal. Storage limits are boundary checks, not filesystem quotas.
- Local Watchdog snapshots and operator notifications preserve observed metadata with content excluded by default. Watch notifications do not infer process death, retry work or contact another person. Rotating observation logs stop at capacity without deleting records; an interrupted unsealed journal is incomplete. Continuous external exporters are optional and unqualified.
- Default MCP and Factory Floor remain read-only. Separate POSIX control grants authorize bounded operations; they are not remote or multi-user authentication. Official SDK1.32.2 stdio interoperability passed. Editor-specific host certification and remote transports require separate qualification.
- Git adapters prepare isolated source, commits, conflict reports and unpublished PR packets. Actual public CI inspection passed against the recorded historical commit. The target repository had no public issues during qualification; a positive issue-ingestion run was not fabricated. Nothing locally passing authorizes push, PR publication, review posting, merge or deployment. External delivery remains separately permissioned.
- Catalog maintenance compares immutable roster, metadata, schema, dependency and resource changes without adopting them. It does not automatically prove compatibility or provide a complete security-advisory feed.
- Fresh Linux/macOS CI installs, current-source clean-checkout missions, offline upgrade/rollback and final engine/security tests must be judged from their exact qualification records. Earlier same-host observations do not prove clean OS or universal platform compatibility. WSL2 has an explicit assessment, not a live qualification claim.
