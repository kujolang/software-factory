# Known limitations

This is a substantial integration increment, **not the requested feature-complete release**. Do not publish it as that release. The acceptance manifest records open requirements rather than equating files or mocked tests with completion.

- Complete catalogs are installed and integrity checked. All 85 manifests and 170 role input/output schemas validate; all 28 Chain of Command roles are discoverable. The executable Dispatch workflow still uses its established fixed role subset. Arbitrary team execution, every role's semantic handoffs, role-specific provider selection and performance evaluation are unfinished. Canonical Chain schemas permit extra fields and do not require their described semantic outputs.
- The 136 skills are packaged completely and activations have receipts. Activations select guidance only; they do not yet inject skills into every mission. Uniform dependency metadata is unavailable upstream. Skill execution accounting, compatibility evaluation and automatic routing beyond bounded advisory plans are unfinished.
- The 45 workflow kits are discoverable with upstream maturity labels. The 20 software mission types have advisory team policies, not qualified executable lifecycle templates. Upstream audit metadata lists only 44 kits; the README additionally lists Publishing House Operator.
- Spec is executed before pack-based Dispatch missions, with frozen pack and requirement/test traceability. Default missions without packs retain their old contract. Semantic contradiction detection, independently reviewed generated acceptance suites and contract change-impact analysis remain incomplete.
- RunLedger, CaseFile and ShipCheck execute through bounded adapters but are not automatically wired into all mission stages. ShipCheck remains advisory metadata inspection. Eval, Lens, Fence, Concord, ChangeBucket, Watchdog, context/retrieval, Ability, Relay, Tribunal, Kennel and other audited capabilities still need qualified factory adapters. The inventory is not integration evidence.
- Codex and local Ollama pass bounded live schema checks and deterministic conformance. End-to-end missions using the extracted provider layer, provider comparison and per-role models remain unqualified. Anthropic, Gemini and other providers are audited only. Cost ceilings fail closed because no verified reservation/accounting adapter exists. Mock mode is inaccessible from production provider settings.
- Supported construction remains standard-library Node HTTP, optional SQLite and static browser files. TypeScript, Python, Go, Rust, Kujo, package-managed frameworks, PostgreSQL and dependency builds have no newly qualified runtime profiles.
- Evidence integrity, source binding and optional trusted-key signatures work offline. They do not prove actual execution, human identity or deployment authority. Import archives evidence; it cannot resume a mission. Old runs lack execution-start provenance and remain explicitly unknown.
- The local MCP interface is read-only discovery/planning/scoped verification. Submission, authenticated owned-mission cancellation, approval routing and external-host interoperability are incomplete. Factory Floor adds catalog inspection but not complete provider, cost, failure, diff and recovery dashboards.
- Repository onboarding, isolated branch/PR preparation, GitHub issue/CI integration and separately authorized deployment adapters remain unfinished. No deployment permission is inferred.
- Existing watchdog death cleanup passes. Durable checkpoint continuation, external-effect reconciliation, budgets, concurrency/storage policy, retention, rotation, backup/restore and notification controls are unfinished.
- Current-machine setup and runtime checks pass; fresh Linux/macOS installations, WSL2 assessment, offline installation, upgrade and rollback qualification remain unexecuted. Do not transfer old receipts to new dependencies or images.
- Upstream VideoOps validator `scripts/validate_videoops.kujo` fails under Kujo 1.9.0 with `Stack underflow`. Independent AJV/Python checks pass but do not resolve that failure. The agent manifest schema correction is pinned from an upstream review branch, not represented as a merged release.

Foreman is excluded. Cloud, remote Workcell, private Ward, Capsule and commercial services are not required. No unavailable capability silently falls back to host execution.
