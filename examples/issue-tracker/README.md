# Factory 01 issue tracker

A dependency-free local team issue tracker generated by canonical Chain of Command roles. Node 26.12.1 or newer. No installation hooks or third-party app packages.

## Run

Host execution below is for manually reviewed, trusted source only. Use the factory Workcell harness for untrusted candidates.

`npm start` or `node server.mjs`. Set PORT (default 4381) and DB_PATH (default ./issues.sqlite). Open http://127.0.0.1:4381. SQLite persists across restarts. Keep your database outside a replaceable build directory when upgrading.

Use project controls to create, edit or delete projects. Task dialogs support title, description, priority, assignee and status. Board lanes are todo, doing and done; edit status to move a task without dragging. Activity shows changes for the selected project. Deleting a project cascades its tasks and activity.

## Test and production candidate

`node factory/acceptance.mjs APP_PATH EVIDENCE_DIR` from the trusted agent-city checkout runs 30 REST, validation, activity, cascade, static-serving and restart-persistence checks against a rootless Workcell lease. The factory also runs browser and syntax checks inside Workcell; candidate code never executes on the controller host. `npm run build` syntax-checks the runtime and emits checksums for the JavaScript runtime files; no transpilation is necessary. The factory copies exactly reviewed/tested source into its build directory and records SHA-256 digests in artifacts/release.json. Browser tests are run by the factory's Playwright harness before release and retained beside the candidate.

## REST

GET/POST /api/projects, PATCH/DELETE /api/projects/:id; GET/POST /api/tasks, PATCH/DELETE /api/tasks/:id; GET /api/activity?projectId=N; GET /api/health. Task fields: projectId, title, description, status (todo/doing/done), priority (low/medium/high), assignee. Lists return arrays, mutations return objects; errors use {error:string}. Requests must use loopback Host; cross-origin browser writes are rejected.

## Limits

Single local operator, no authentication or public-hosting qualification. Do not expose the port externally. Local host execution is not a security sandbox. Never treat a successful model review as a substitute for acceptance checks.
